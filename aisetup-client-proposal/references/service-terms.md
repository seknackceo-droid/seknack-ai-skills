# サービス条件・見積境界

## 正本の優先順位

毎回、営業管理スプレッドシートの `99_設定` を先に読む。この文書は2026-08-28時点の確認済みスナップショットであり、ライブ設定と違う場合はライブ設定を優先する。

## 確認済みスナップショット

| 項目 | 条件 |
|---|---|
| 基準価格 | 300,000円・税別 |
| 先行導入価格 | 150,000円・税別 |
| 対象 | 1社・PC1台・主利用者1名・1業務 |
| 支払い | 着手時50％・完成時50％ |
| 修正 | 完成後30日以内の修正対応 |
| 導入 | オンラインを基本とし、顧客側PCへ導入する |
| 操作説明 | 顧客本人がその場で1回実行できる状態を目指す |
| 基本マニュアル | Codexの基本操作マニュアルを渡す |
| 個別業務の操作 | 操作説明を行う。個別スキル専用マニュアルは標準に含めない |
| 月額サービス名 | AIエージェント活用伴走プラン |
| 月額料金 | 10,000円・税別 |
| 月額加入 | 任意。加入した場合の最低利用期間は6か月 |
| 受付 | 24時間受付可能 |
| 回答 | 原則2営業日以内 |
| 質問回数 | 無制限 |
| 月額に含む | AIエージェントの使い方に関する質問回答 |
| 月額に含まない | 操作代行、新規ツール・新規スキル開発、別業務の追加 |
| 連絡手段 | 個別LINEグループを基本候補とし、公式LINEを記録保持用に参加させる |

税区分を落とさない。税込額は必要な場合だけ正しく計算し、税率と計算日を明記する。

## 1業務の考え方

1つの業務は、1つの目的に向かう次の連続として扱う。

```text
きっかけ → 入力 → AIまたはツールの処理 → 人間確認 → 1つの主出力
```

例: 請求書をまとめ、確認用PDFとして出力する。別部署へ渡した後に別目的の処理を行う場合は、2業務目の候補になる。

## 標準範囲の候補

- PC1台で実行する
- 主利用者1名
- 目的と主出力が1つ
- 通常フローを中心に設計できる
- 顧客が必要なアカウントと権限を用意する
- 人間の最終確認を残せる
- データ移行や大規模な初期整備を必要としない

認証や外部サービス操作があるだけで自動的に追加料金にはしない。全体の手順、例外、保守負荷を見て判断する。

## 複雑性シグナル

次のいずれかがある場合は追加見積候補として技術確認へ回す。

- 実質的に目的または主出力が2つ以上
- 複数部署・複数利用者・複数PCで使う
- 複数アカウント、複雑な認証、頻繁な2段階認証がある
- API、基幹システム、会計、CRM、LINE、Slack等との連携が必要
- 無人の定時実行、常時監視、高い可用性が必要
- 大量のデータ移行、名寄せ、初期整備が必要
- 例外分岐が多く、通常フローだけで成立しない
- 外部送信や公開をAIが自動で確定・実行することを求める
- 個人情報、契約、法務、税務、労務、金額判断など高リスク判断を含む
- 受注後も運用代行や継続開発を求める

## 見積ルール

- 標準条件と技術確認が揃えば、ライブ設定の先行導入価格を提示できる。
- 複雑性シグナルがある場合、追加理由を工程単位で示す。
- 追加金額の自動計算表は現時点で未確定。AIは独自の金額を創作しない。
- 追加金額は、技術担当と最終承認者が明示した金額を使う。
- 見積金額が未承認なら「見積案 / 要確認」とし、顧客提出用画像へ確定値として入れない。

## 納期ルール

標準納期は現時点のライブ設定にない。顧客提出前に必ず技術担当または最終承認者が確定する。AIが一般的な日数を推測しない。

## 外部費用

ChatGPT、Codex、各SaaS、クラウド、API、PC、通信等の第三者費用が本体価格に含まれるかは、現時点の正本で一律確定していない。案件で必要な場合は明示確認し、勝手に「込み」「別途」と断定しない。

## 修正と追加開発

30日以内の修正対応は、合意済みの1業務と納品範囲に関する修正として扱う。別業務、新しい出力、新規連携、運用代行は30日修正に含めず、追加見積候補とする。
