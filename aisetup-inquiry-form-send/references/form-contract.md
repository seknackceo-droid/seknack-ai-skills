# フォーム入力契約

## 営業リスト

| 列 | 項目 | 用途 |
|---|---|---|
| F | 問い合わせフォームURL | 開くフォーム |
| H | 送信担当 | 送信者マスタの検索キー |
| I | 送信状況 | 完了後のみ更新 |
| J | 送信日 | 完了後のみ更新 |
| N | 送信文（署名込） | 本文へ入力 |
| O | 承認状況 | `承認OK` のみ処理 |
| P | 送信キュー | `送信待ち` のみ処理 |
| Q | 除外・処理メモ | エラー、確認事項、結果を記録 |

## 送信者マスタ

`99_設定` のK列からV列を、H列の送信担当名で検索する。

| 列 | 項目 | 標準的なフォーム表示 |
|---|---|---|
| K | 営業担当 | 氏名、担当者名、お名前 |
| L | 電話番号 | 電話、TEL |
| M | 共通メール | メール、E-mail |
| N | 署名 | 本文にはN列の送信文を優先 |
| O | 会社名 | 会社名、法人名 |
| P | 部署名 | 部署、所属 |
| Q | 役職 | 役職 |
| R | 氏名カナ | フリガナ、氏名カナ |
| S | 郵便番号 | 郵便番号、〒 |
| T | 住所 | 住所、所在地 |
| U | 会社URL | URL、Webサイト |
| V | 利用状態 | `有効` の担当者だけ使用 |

## 入力原則

- 表示ラベルを最優先し、name属性、placeholderを補助にする
- 姓名が分割されていて分割根拠がない場合は推測せず止める
- 電話番号や郵便番号のハイフン要否は入力欄の制約に合わせる
- 確認画面がある場合も、最終確定ボタンは人間に残す
- 送信完了表示が出るまでスプレッドシートを送信済みにしない
